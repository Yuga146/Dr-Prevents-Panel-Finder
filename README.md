# Klinik Dr. Prevents — Panel Finder, TPA & Insurance Directory

A sleek, responsive, and user-friendly web application designed for the Control Centre Department (CCR) and staff at **Klinik Dr. Prevents** to instantly verify and look up accepted Third-Party Administrator (TPA) panels, corporate clients, and insurance partners across branch locations.

---

## 🌟 Key Features

*   **⚡ Instant Search & Filtering:** Quickly search panels and insurance providers by name, category, or branch availability.
*   **🏥 Branch-Specific Directory:** Seamlessly filter panels accepted across different Klinik Dr. Prevents clinic branches in Kuala Lumpur and Selangor.
*   **🏢 TPA & Insurance Categorization:** Clear classification of corporate clients, insurance panels, and managed care organizations.
*   **🎨 Professional UI/UX:** Styled with an elegant black and gold executive theme designed for fast-paced clinical operations and control centre dispatch workflows.
*   **📱 Fully Responsive:** Optimized for desktop monitors at clinic front desks as well as mobile devices for staff on the go.
*   **🚀 Zero-Config Deployment:** Built with pure HTML, CSS, and JavaScript, hosted seamlessly on GitHub Pages.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Styling:** Custom CSS with responsive flex/grid layouts and a signature black & gold palette
*   **Hosting:** GitHub Pages

---

## 🚀 Usage

1. Access the live web app via GitHub Pages.
2. Use the search bar to type in an insurance company, corporate employer, or TPA name.
3. Filter by specific branch locations to confirm immediate panel acceptance and coverage details.
